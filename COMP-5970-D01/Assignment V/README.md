# Assignment V — Sky Roller: Endless Survival

An endless procedural runner built on the Module 5 **Sky Roller 3D** game, in
**Unity 6 (6000.4.8f1)** / URP. Platforms generate ahead and recycle behind the
player, hazards disrupt you, and a survival score tracks how long you last.

## Play

1. Add this `Assignment V` folder via **Unity Hub → Add project from disk** (Unity 6000.4.x).
2. Open `Assets/Scenes/GameScene.unity` and press **Play**.

| Action | Key |
| --- | --- |
| Steer | A / D (or arrows) |
| Restart after losing | R, or the **Restart** button |

## Features

- Procedural platform generation (4 section types) that spawns ahead and removes behind.
- Hazards: **Kill**, **Slow**, **Bumper**, **Reverse** (+ **Boost** pickup).
- Survival score (distance + time + sections) on a UI HUD.
- Lose by falling off or hitting a spike; restart flow built in.

3D models from the [Kenney Platformer Kit](https://kenney.nl/assets/platformer-kit) (CC0).
